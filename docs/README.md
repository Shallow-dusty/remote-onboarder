## 文档职责

README 负责上手；`build.md` 负责实现流程与维护；STATUS 是当前验证摘要；审计
保留发现和边界。修改构建输入时同步 README / build.md / config.example.json。

`build/` 为忽略的本地输出目录，不是发布文档：私密配置、载荷、日志、合成自检
输出和截图都不提交。自检证据与线上运行证据严格区分。

## 排障顺序

1. 读取终端错误与本地日志，不因“可重跑”就反复双击。
2. pending 标记存在时，先核查相应安装/子进程/配置恢复状态；不要仅删除标记。
3. 复杂策略或不同 Tailnet 阻止自动操作时，在目标机本地人工审查。
4. 本机检查通过后，将连接信息交给控制者核对主机指纹并实际试连。
5. 日志同步失败不等于安装失败；面板保留的旧内容不代表目标机仍在运行。
